# 학생관리 대시보드 (강사용)

7개 반을 관리하기 위한 로컬 웹 대시보드입니다. 설치가 필요 없고, 이 폴더 안에서만 동작합니다.

## 시작하는 법

1. `시작하기.bat` 파일을 더블클릭하세요. 브라우저가 자동으로 열립니다.
2. 다음부터도 항상 이 파일로 열어주세요 (index.html을 직접 더블클릭하면 동작하지 않습니다).
3. 창을 닫아도 데이터는 남아있습니다. 다시 `시작하기.bat`을 실행하면 이어서 사용할 수 있습니다.

## 화면 구성

- 상단: **1반 ~ 7반** 탭 (반 이름 더블클릭 시 이름 변경 가능)
- 반별 하위 탭
  - **학생정보**: 명단, 학생/학부모 연락처, 재원상태 — 표에서 바로 클릭해 수정
  - **출결현황**: 날짜 선택 후 출석/지각/조퇴/결석 클릭, 최근 기록 로그 + 출석률 요약
  - **숙제현황**: 날짜별 제출상태 + 특징 메모(예: "오답 많음"), 최근 기록 로그
  - **성적추이**: 시험 성적 입력 → 학생별 성취율(%) 꺾은선 그래프, 반 평균 표시 가능
  - **데이터 가져오기**: 엑셀에서 저장한 CSV 파일을 업로드해 한 번에 반영

## 엑셀 데이터 올리는 법

1. 엑셀에서 **다른 이름으로 저장 → CSV UTF-8(쉼표로 분리)** 선택해서 저장
   (일반 "CSV"로 저장하면 한글이 깨질 수 있으니 꼭 "UTF-8"이 붙은 옵션을 선택하세요)
2. 각 반의 **데이터 가져오기** 탭에서 "○○ 템플릿 내려받기" 버튼으로 양식을 먼저 받아 열이 맞는지 확인하세요.
3. 완성한 CSV 파일을 **파일 선택**으로 올리면, 제목행(헤더)을 보고 학생명단/출결/숙제/성적 중 무엇인지 자동으로 구분합니다. 여러 파일을 한 번에 선택해도 됩니다.
4. **이름은 그 반의 학생명단과 정확히 일치**해야 매칭됩니다. 이름이 다르면 화면에 "매칭 실패 목록"으로 알려줍니다 — 오타를 고치고 다시 올리면 됩니다.

### 파일별 열(컬럼) 형식

| 파일 | 열 |
|---|---|
| 학생명단 | 이름, 학생연락처, 학부모연락처, 학부모관계, 상태(재원/휴원/퇴원) |
| 출결 | 날짜(YYYY-MM-DD), 이름, 상태(출석/지각/조퇴/결석) |
| 숙제 | 날짜(YYYY-MM-DD), 이름, 상태(완료/부분완료/미완료), 메모 |
| 성적 | 날짜(YYYY-MM-DD), 이름, 과목, 시험명, 점수, 만점 |

## 데이터는 어디에 저장되나요

`data\store.json` 파일에 저장됩니다 (브라우저가 아니라 이 폴더 안입니다). 그래서:

- **다른 컴퓨터에서 쓰려면**: 이 `claude-test` 폴더를 통째로 복사하거나, OneDrive/구글드라이브 같은 동기화 폴더 안에 넣어두세요. 그 컴퓨터에서도 `시작하기.bat`으로 열면 같은 데이터가 그대로 보입니다. (단, 두 컴퓨터에서 동시에 켜놓고 입력하면 안 됩니다 — 나중에 저장한 쪽이 덮어씁니다.)
- 화면 우측 상단의 **백업 내려받기**로 정기적으로 백업 파일(json)을 따로 저장해두면 더 안전합니다.

## 휴대폰이나 같은 사무실 다른 컴퓨터에서 접속하기

`http://127.0.0.1:8791/...` 주소는 **이 컴퓨터 자신**만 가리키는 주소라서 다른 기기에서는 그대로 입력해도 열리지 않습니다. 같은 Wi-Fi(네트워크)에 연결된 휴대폰이나 다른 컴퓨터에서 보려면:

1. `휴대폰다른기기에서보기.bat`을 더블클릭하세요.
2. **관리자 권한 확인(UAC)** 창이 뜨면 '예'를 누르세요 (Windows가 다른 기기의 접속을 허용하려면 필요합니다).
3. **Windows Defender 방화벽** 알림이 뜨면 '액세스 허용'을 누르세요.
4. 안내 창에 뜨는 주소(예: `http://192.168.0.12:8791/index.html`)를 다른 기기의 브라우저에 입력하세요.

주의: 이 방법은 **같은 Wi-Fi/네트워크 안에서만** 동작합니다 (인터넷 어디서나 되는 건 아닙니다). 학생·학부모 전화번호가 들어있는 화면이니, 같은 공간에 있는 사람만 접속할 수 있는 이 방식이 안전합니다 — 인터넷 전체에 공개하는 것은 별도로 요청해주세요(로그인 기능이 꼭 필요합니다).

## 참고

- 이 폴더를 zip으로 압축해서 전달할 때는 `data` 폴더도 꼭 함께 보내야 데이터가 같이 갑니다.
- 학생을 삭제하면 그 학생의 출결/숙제/성적 기록도 함께 삭제됩니다.
- 화면 상단에 빨간 경고 배너가 뜨면 저장이 안 되고 있다는 뜻입니다 — `시작하기.bat`으로 켜져 있는지 확인해주세요.
